# 🐙 Hide & Ink(문어의 먹물꿈질)

본 문서는 팀 프로젝트 "Hide & Ink(문어의 먹물꿈질)"의 원활한 깃허브 협업을 위한 팀원별 역할 및 작업 바운더리 가이드라인입니다. 모든 팀원은 작업 시작 전 본인의 담당 폴더와 접근 금지 폴더를 숙지해 주시기 바랍니다!

---

## 🔄 이상적인 작업 파이프라인 (작업 흐름도)

효율적인 개발과 깃허브 충돌(Conflict)을 방지하기 위해 아래의 파이프라인 순서대로 작업을 인계하는 것을 권장합니다.

1. **🎨 비주얼 에셋 세팅 (박미초):** `Assets/Art` 폴더에 공식 리소스와 셰이더를 세팅하고 깃허브에 **Push** 합니다.
2. **⚙️ 핵심 뼈대 구축 (김동열):** `Assets/Scripts/Core`에 튼튼한 코드를 작성하여 **Push** 합니다.
3. **🧩 조립 및 통합 (박시연):** 아트 리소스와 코드를 받아(Pull), 하나로 결합한 프리팹(Prefab)을 만들어 **Push** 합니다.
4. **📐 레벨 배치 및 튜닝 (장지은):** 시연님이 만든 조립식 프리팹들을 씬에 배치하고, 밸런스 수치를 조절하여 **Push** 합니다.

> **💡 팀 공통 필수 약속**
> - 작업 파일(이미지 등)을 개별 단톡방으로 공유하지 않습니다. 지정된 자신의 **폴더 경로에 올바르게 저장한 후 GitHub을 통해 공유**합니다.
> - 타인의 폴더 구역에 있는 파일의 이름을 바꾸거나 위치를 이동하면 유니티 구조에 치명적인 에러가 발생하므로 **반드시 사전 상의 후 수정**합니다.
