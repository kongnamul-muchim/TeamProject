## 1. 개요

플레이어가 보유한 특수 능력을 **도주 능력**과 **보스 능력** 두 가지 체계로 분리하여 관리하는 시스템이다. 두 능력은 공통 자원인 **잉크 게이지**를 소모하며, 각각 독립된 슬롯에 할당된다.

---

## 2. 슬롯 구조

```
[특수 능력 슬롯 - 총 2개]
┌─────────────────────┬─────────────────────┐
│  슬롯 1: 도주       │  슬롯 2: 보스       │
│  (고정)             │  (가변)             │
│                     │                     │
│  먹물 분사 (고정)   │  스테이지 클리어    │
│                     │  시 획득/교체       │
└─────────────────────┴─────────────────────┘
```

| 항목 | 도주 슬롯 | 보스 슬롯 |
|------|-----------|-----------|
| **할당** | 고정 (변경 불가) | 가변 (스테이지 클리어 시 교체) |
| **발동 조건** | 발각 상태 (Detected) | 일반 상태 (Playing) |
| **입력 키** | SPACE (기본) | Q (기본) |
| **소모 자원** | 잉크 게이지 | 잉크 게이지 |
| **소모량** | 적음 (30) | 많음 (50) |

---

## 3. 도주 능력: 먹물 분사

### 3.1 개요
| 항목 | 내용 |
|------|------|
| **출처** | 오징어 (고정) |
| **유형** | 긴급 회피 |
| **발동 조건** | GameState == `Detected` |
| **효과** | 포식자 시야 차단 + 플레이어 이동속도 증가 |

### 3.2 효과 상세
```
[먹물 분사 발동]
    ↓
1. 먹물 VFX 전방 발사 (시야 차단 영역 생성)
    ↓
2. 플레이어 이동속도 ×2.0 배 증가 (3초간)
    ↓
3. 잉크 게이지 -30 소모
    ↓
4. 지속 시간 종료 or 잉크 부족 시 효과 해제
    ↓
5. 성공 시: GameState → Escaped → Playing
```

### 3.3 수치
| 항목 | 기본값 | 설명 |
|------|--------|------|
| **소모 잉크** | 30 | 발동 시 즉시 차감 |
| **지속 시간** | 3초 | 가속 효과 유지 시간 |
| **이동속도 배율** | ×2.0 | 기본 이동속도 대비 |
| **시야 차단 반경** | 3m | 포식자 시야 가리는 영역 |
| **쿨타임** | 없음 | 잉크만 충분하면 연속 사용 |

## 4. 보스 능력

### 4.1 개요
스테이지(챕터) 클리어 시 해당 보스의 능력을 획득하여 보스 슬롯에 등록한다. 새로운 보스 능력 획득 시 기존 능력은 **덮어씌워진다**.

### 4.2 보스 능력 목록

| 챕터 | 보스 | 능력명 | 효과 | 활용 |
|------|------|--------|------|------|
| **Ch.1** | 가자미 | **모래 매복** | 바닥에 숨어 이동, 의심도 증가 억제 | 은신 이동 |
| **Ch.2** | 곰치 | **맹독 추격** | 이동속도 증가 + 포식자 위치 감지 | 역추적/회피 |
| **Ch.3** | 전기뱀장어 | **전기 방어망** | 주변 적 감전 + 접근 차단 | 방어 |
| **Ch.4** | 아귀 | **발광 미끼** | 빛나는 미끼 생성, 포식자 시선 유도 | 기만 |
| **Ch.5** | 백상아리 | **수직 절단 돌진** | 강력한 돌진 + 방해 오브젝트 파괴 | 돌파 |

### 4.3 공통 수치
| 항목 | 기본값 | 설명 |
|------|--------|------|
| **소모 잉크** | 50 | 발동 시 즉시 차감 |
| **지속 시간** | 능력별 상이 | 각 능력별 별도 정의 |
| **쿨타임** | 없음 | 잉크만 충분하면 연속 사용 |

### 4.4 능력별 상세 (추후 구현 시 구체화)

#### Ch.1 모래 매복
| 항목 | 내용 |
|------|------|
| **지속 시간** | 5초 |
| **효과** | 의심도 증가 50% 감소, 이동 가능 |
| **VFX** | 모래 질감으로 변신 + 모래 입자 효과 |

#### Ch.2 맹독 추격
| 항목 | 내용 |
|------|------|
| **지속 시간** | 4초 |
| **효과** | 이동속도 ×1.5, 포식자 방향 UI 표시 |

#### Ch.3 전기 방어망

#### Ch.4 발광 미끼

## 5. 잉크 게이지 시스템

### 5.1 개요
도주 능력과 보스 능력이 공유하는 자원이다. 단일 게이지로 관리되며, 두 능력의 소모량이 다르다.

### 5.2 구조
```
[InkGauge]
├── 현재 잉크: 0 ~ 최대 잉크
├── 자연 회복: 초당 회복량만큼 지속 증가
├── 도주 사용: -30 (즉시 차감)
├── 보스 사용: -50 (즉시 차감)
└── 치치 근처: 회복 속도 ×2 (보너스)
```

### 5.3 인스펙터 설정값
모든 수치는 Unity 인스펙터에서 `[SerializeField]`로 노출되어 디자이너가 직접 조절 가능하다.

| 필드명 | 타입 | 기본값 | 설명 |
|--------|------|--------|------|
| `maxInk` | float | 100 | 최대 잉크량 |
| `currentInk` | float | 100 | 시작 잉크량 |
| `escapeCost` | float | 30 | 도주 능력 소모량 |
| `bossCost` | float | 50 | 보스 능력 소모량 |
| `recoveryRate` | float | 5 | 초당 자연 회복량 |
| `escapeDuration` | float | 3 | 도주 효과 지속 시간 |
| `escapeSpeedMultiplier` | float | 2.0 | 도주 시 이동속도 배율 |
| `chiChiRecoveryMultiplier` | float | 2.0 | 치치 근처 회복 배율 |
| `chiChiDetectionRadius` | float | 3 | 치치 근처 판정 반경 |

### 5.4 게이지 UI
```
[화면 하단 - 텍스트/바 조합]
Ink: ████████████░░░░░░░░ 60/100
```
- 게이지 색: 진한 남색 (#1A237E)
- 부족 시 (10% 미만): 붉은색 경고 깜빡임

## 6. 상태별 사용 규칙

### 6.1 GameState 별 능력 사용 가능 여부

| GameState | 도주 능력 | 보스 능력 |
|-----------|-----------|-----------|
| **Playing** | ❌ 사용 불가 | ✅ 사용 가능 |
| **Detected** | ✅ 사용 가능 | ❌ 사용 불가 |
| **Escaped** | ❌ 사용 불가 | ❌ 사용 불가 |
| **Paused** | ❌ 사용 불가 | ❌ 사용 불가 |
| **Dead** | ❌ 사용 불가 | ❌ 사용 불가 |

### 6.2 흐름도
```
[Playing 상태]
    ├─ 보스 능력 사용 (Q) → 잉크 충분? → 효과 발동
    ├─ 포식자 발견 → 의심도 100%
    └─ GameState → Detected

[Detected 상태]
    ├─ 도주 능력 사용 (SPACE) → 잉크 충분? → 효과 발동
    ├─ 시야 차단 성공?
    │   ├─ YES → GameState → Escaped → Playing
    │   └─ NO → 포식자 접촉 → GameState → Dead
    └─ 잉크 부족 → 도주 불가 → Dead 위험
```

## 7. 보스 능력 획득 흐름

```
[보스방 진입]
    ↓
[보스 패턴 회피/관찰]
    ↓
[스테이지 클리어 조건 달성]
    ↓
GameEvents.OnStageClear 발생
    ↓
[해당 챕터 보스 능력 잠금 해제]
    ↓
보스 슬롯에 새 능력 등록 (기존 능력 덮어쓰기)
    ↓
[화면 알림: "새 능력 획득! - ○○○"]
```
