> **버전:** v1.1
> **작성일:** 2026-04-24
> **문서 상태:** 계획단계
> **변경:** 몬스터 구성 정리 — 보스 4종(아귀제거), 정예 2종(청새치개선+바다거북), 일반 2종(게+성게)

---

## 1. 개요

### 1.1 목적
HideAndSeek 게임의 Enemy 이동 AI 시스템을 구축한다. 보스 몬스터를 중심으로 하며, 일반 몬스터와 정예 몬스터로 확장 가능한 구조로 설계한다.

### 1.2 핵심 요구사항
- 보스 몬스터: Patrol → Chase → Search 상태 전환 (의심도 기반)
- 일반 몬스터: 단순 이동 + Player 접촉 시 보스에게 위치 알림
- 정예 몬스터: 기믹형 (복어 등), Player 접근 시 몸 부풀려 길 막기
- 부드러운 이동: 가속도/마찰력 기반 자연스러운 움직임
- 시야 방향: Enemy 자식 `Enemy_Forward`를 사용한 Y축 회전 처리

## 2. Enemy 타입별 역할

### 2.1 보스 몬스터 (Boss Enemy)

| 항목 | 설명 |
|------|------|
| **역할** | 메인 추적자. Player를 발견하면 추격 |
| **의심도** | 상승/하락 있음 (SuspicionMeter 연동) |
| **AI 상태** | Patrol, Chase, Search |
| **이동 방식** | 가속도/마찰력 기반 부드러운 이동 |
| **시야** | ConeVisionSensor + VisionConeRenderer |

### 2.2 일반 몬스터 (Normal Enemy)

| 항목 | 설명 |
|------|------|
| **역할** | 정찰병. 보스 몬스터의 '눈과 귀' |
| **의심도** | 없음 |
| **AI 상태** | 단순 이동 (AI 상태 머신 없음) |
| **특수 기능** | Player 접촉 시 보스에게 Player 위치 알림 |
| **이동 방식** | 단순 이동 (속도 고정) |

### 2.3 정예 몬스터 (Elite Enemy)

| 항목 | 설명 |
|------|------|
| **역할** | 기믹형 몬스터 (예: 복어) |
| **의심도** | 없음 |
| **AI 상태** | 대기 → Player 접근 시 기믹 발동 |
| **특수 기능** | 몸 부풀려 길 막기, 낮은 속도로 통과 가능 |
| **확장성** | 기믹 인터페이스 분리 (향후 추가 기믹 쉽게 확장) |

- 기습 돌진 시 짧은 시간 동안 속도 대폭 증가

## 4. 보스 AI 상태 흐름

### 4.1 상태 정의

| 상태 | 설명 | 진입 조건 | 이탈 조건 |
|------|------|-----------|-----------|
| **Patrol** | 랜덤 순찰 | 초기 상태, Search 시간 초과, 의심도 하락 | 의심도 ≥ Danger(60), Player 시야 내 발견 |
| **Chase** | Player 추적 | 의심도 ≥ Danger, Player 시야 내 발견 | Player 시야에서 사라짐, 의심도 하락 |
| **Search** | 마지막 위치 기반 탐색 | Chase 중 Player 시야에서 사라짐 | Player 재발견, 5초 경과, 의심도 하락 |

### 4.2 상태 전환 다이어그램

```
                    의심도 ≥ Danger
                    Player 시야 내 발견
[Patrol] ──────────────────────────────→ [Chase]
   ↑                                        │
   │                                        │ Player 시야에서 사라짐
   │                                        │ 의심도 하락
   │                                        ↓
   │                                     [Search]
   │                                        │
   │                    ┌───────────────────┤
   │                    │                   │
   │  Player 재발견     │ 5초 경과          │ 의심도 ↓
   └────────────────────┴──────── Patrol ←──┘
```

### 4.3 의심도 임계값

| 임계값 | 값 | 효과 |
|--------|-----|------|
| Caution | 30 | 주의 상태 (AI 변화 없음) |
| Danger | 60 | Chase 상태로 전환 |
| Critical | 80 | Chase 가속도 증가 |
| Detected | 100 | GameStateMachine.Detected 전환 |

## 5. 이동 시스템

### 5.1 EnemyMovement (보스 몬스터)

| 항목 | 설명 |
|------|------|
| **가속도** | 목표 속도까지 부드럽게 가속 (Lerp 기반) |
| **마찰력** | 입력 없을 시 서서히 정지 |
| **최대 속도** | 상태별로 다름 (Patrol < Chase < Search) |
| **방향 전환** | 자연스럽게 회전 (즉시 방향 전환 없음) |

### 5.2 상태별 속도 설정

| 상태 | 속도 | 설명 |
|------|------|------|
| Patrol | 느림 | 랜덤 순찰, 여유로운 이동 |
| Chase | 빠름 | Player 추적, 예측 이동 |
| Search | 중간 | 마지막 위치 탐색, 신중한 이동 |

### 5.3 Chase 상태의 "자연스러운 추격"

- **예측 이동**: Player 현재 위치 + 이동 방향 × 0.5초 지점 추적
- **부드러운 가속**: PlayerMovement와 동일한 Lerp 시스템
- **시야 회전**: Player 방향으로 자연스럽게 회전

## 6. 시야 시스템

### 6.1 시야 방향 처리

| 항목 | 설명 |
|------|------|
| **방식** | Enemy 자식 `Enemy_Forward` Transform 사용 |
| **회전** | Y축 회전만 처리 (X축 고정 해제) |
| **기본 방향** | 왼쪽 (Y=0) |
| **좌우 표현** | Enemy의 Y값을 180도 회전하여 처리 |

### 6.2 부채꼴 표시

| 항목 | 설명 |
|------|------|
| **바닥 부채꼴** | `VisionConeRenderer` - 실제 감지 영역 표시 |
| **3D Gizmos** | `ConeVisionSensor.OnDrawGizmosSelected()` - 디버깅용 |
| **사용 방식** | 바닥 부채꼴만 참조 (3D Gizmos는 무시) |

### 6.3 시야 패턴

| 패턴 | 각도 | 반경 | 용도 |
|------|------|------|------|
| Patrol | 45° | 4m | 순찰 시 좁은 시야 |
| Observe | 90° | 6m | 관찰 시 넓은 시야 |
| Guard | 120° | 5m | 경계 시 매우 넓은 시야 |

## 10. 테스트 계획

### 10.1 단위 테스트
- Patrol 상태: 랜덤 순찰 정상 동작
- Chase 상태: Player 추적, 부드러운 가속
- Search 상태: 마지막 위치 탐색, 시간 초과 복귀
- 상태 전환: 의심도 기반 전환 정상 동작

### 10.2 통합 테스트
- 보스 몬스터: Patrol → Chase → Search → Patrol 흐름
- 일반 몬스터: Player 접촉 시 보스에게 위치 알림
- 정예 몬스터: Player 접근 시 기믹 발동
