# X-Ray 의태(Camouflage) 시스템 최종 완료 보고서

> 작성일: 2026-04-22
> 대상 컴포넌트: `OctopusCamouflage_Body.shader`, `OctopusCamouflage_Outline.shader`, `XRayMaterialDualizer.cs`

## 1. 개요 및 달성 목표
- 장애물(바위, 산호 등) 뒤에 캐릭터(문어)가 숨었을 때, 완전히 가려지지 않고 투명한 외곽선만 식별되는 'X-Ray 투과' 시각 효과를 물리 엔진 렌더러 수준에서 완벽하게 안정화함.

## 2. 발생했던 문제점 (Issue Tracking)
1. **깊이 카메라 누락 문제**: Unity URP 2D Forward 환경에서, SpriteRenderer가 Opaque Queue 설정을 무시하고 강제로 Transparent 큐로 처리되며 깊이 맵(`_CameraDepthTexture`) 기록 과정을 건너뛰는 현상 발견.
2. **이차적 파생 변수**: 수식을 렌더 파이프라인의 강제 `DepthOnly` 패스로 보완했으나, 2D 게임의 특성상 Sorting Layer 최적화로 인해 Z축 깊이가 완전히 동일하게 처리되거나 의도와 다르게 찍혀 "앞/뒤" 판정 로직이 계속해서 무력화됨.
3. **눈 디스플레이 오류**: 마스크 시트 압축 노이즈 혹은 계산 오류로 인해 파란 눈 스펙트럼이 외곽선 조건과 부분 겹침을 일으키는 현상.

## 3. 최종 해결책 구현 내용 (Implementation)
### 3.1 듀얼 머티리얼 방식 도입 (ZTest 하드웨어 로직)
- 수학적인 뎁스 계산의 오류 가능성(0%)을 아예 존재하지 않는 수준으로 격하시키기 위해, 가장 원초적인 하드웨어 Z-Buffer 비교 방식 채택.
- `Mat_Body` (몸통): `ZTest LEqual` 속성으로 장애물 앞에 있을 때만 정상적으로 의태 및 몸통을 그림.
- `Mat_Outline` (외곽선): `ZTest Greater` 속성으로 장애물 뒤에(정확히는 기존 프레임 버퍼 깊이보다 뒤에) 찍힐 때만 강제로 실행됨.

### 3.2 XRayMaterialDualizer.cs 스크립트 작성
- **문제**: 유니티 엔진이 안전을 위해 SpriteRenderer 인스펙터의 머티리얼 배열 렌더링 추가 설정을 강제로 잠그는 문제 확인.
- **해결**: 게임 Awake 구동 시, 단 5줄로 `materials` 배열의 Lock을 해제하고 `Mat_Outline`을 삽입해 단일 SpriteRenderer로 애니메이션 레이어와 시각 레이어를 분리할 수 있게 자동화 스크립트 배포. 확장성과 추후 애니메이션 변신(Skin) 추가에 완벽 대응.

### 3.3 눈동자 렌더링 필터 개선
- 복잡했던 색상(Color) 추출 기반 외곽선 판정을 모두 드랍하고, 유저가 의도했던 **"순수 투명 알파 채널"** 만을 식별하도록 쉐이더의 구문을 극단적으로 간소화함 (`bool isOutline = maskCol.a < 0.05`). 눈 번짐 현상 수복 완료.
