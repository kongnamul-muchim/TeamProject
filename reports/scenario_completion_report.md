# 작업 완료 보고서: 시나리오 및 대사 작성

## 📋 작업 개요
- **작업 내용**: 게임 시작/엔딩 컷씬 및 인게임 대사 데이터 작성
- **목표**: 포트레이트 없이 텍스트만으로 스토리와 정보를 효과적으로 전달
- **대상**: 프롤로그, 플레이 가이드, 보스 4종, 에필로그

## 🛠️ 작업 상세
1. **프롤로그**: 황폐해진 종이 바다의 설정과 두두-치치의 첫 만남 묘사
2. **플레이 가이드**: C(의태), Space(도주), X(잉크 보급) 조작법을 캐릭터 대사/시스템 메시지로 변환
3. **보스 정보**: 청새치, 가자미, 곰치, 백상아리의 특징과 공략 힌트 제공
4. **에필로그**: 두두의 희생과 치치의 기록 보존을 통한 감동적인 마무리
