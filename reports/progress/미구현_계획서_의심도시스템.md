## 📋 현재 구현 상태

### ✅ 완료된 것
- ConeVisionSensor: 부채꼴 시야 감지

- Boss용 추격 상태 머신

## 🎯 미구현 상세 내용

### 1. 일반/정예 몬스터용 시야 감지 시스템

**용도:**
- 일반/정예 몬스터는 Player를 직접 잡는 역할이 아님
- 시야에 Player를 감지하면 방해(방향 알림, 소리 등)만 수행
- 의심도 시스템 없음

**구성 요소:**
```
NormalEnemyVisionSensor (MonoBehaviour)
├── ConeVisionSensor 연동
├── 감지 시 → Player의 CamouflageAdapter/CamouflageDetector에 알림
├── 직접 의심도 관리 안 함
└── 추격 로직 없음
```

**예상 스크립트:**
- `Assets/Core/Perception/NormalEnemyVisionSensor.cs` (신규)

**감지 시 행동:**
- Player 위치 기억 (일정 시간)
- Player가 시야에 들어오면 방해 효과 발생
- CamouflageDetector로 근처 의태 오브젝트 탐지

---

### 2. Boss용 의심도 시스템 고도화

#### 2-1. 거리 기반 감지 강도 계산

**규칙:**
| 거리 구간 | 증가 배율 |
|-----------|-----------|
| 0~2m | 2.0x |
| 2~4m | 1.5x |
| 4~6m | 1.0x |
| 6m 이상 | 0.75x |

**수정 파일:**
- `VisionBasedSuspicionManager.cs` - 거리 계산 추가

#### 2-2. 의태 상태 반영 (증가율 감소)

**규칙:**
| 의태 상태 | 증가 배율 |
|-----------|-----------|
| 미의태 | 1.0x |
| Partial | 0.6x |
| Perfect | 0.3x |

**수정 파일:**
- `VisionBasedSuspicionManager.cs` - 의태 상태 참조
- `CamouflageToSuspicionLink.cs` - 증가율 정보를 VisionBasedSuspicionManager에 전달

#### 2-3. Enemy 근처에서 의심도 증가

**규칙:**
- Player가 Enemy의 감지 범위(시야 + 근처) 바깥으로 벗어나면 의심도 하락
- Player가 Enemy의 근처 범위(시야 밖이지만 가까이)에 있으면 소폭 증가
- 근처 범위: 시야 반경의 1.5배

**수정 파일:**
- `VisionBasedSuspicionManager.cs` - 근처 감지 로직 추가

#### 2-4. 한번 감지되면 추격 (5번 규칙)

**용도:**
- Boss Enemy만 해당 (일반/정예 아님)
- Player가 한 번 시야에 들어오면 도망쳐도 멈추지 않음

**구성 요소:**
```
BossChaseStateMachine
├── Idle: 기본 상태
├── Suspicious: 의심 중 (의심도 30~99%)
├── Chasing: 추격 중 (의심도 100%)
└── LostTarget: 추격 취소 (범위 밖 or 명확히 시야 벗어남)

추격 취소 조건:
- Player가 추격 범위 밖으로 완전히 벗어남
- 또는 의심도가 0%까지 하락
```

**예상 스크립트:**
- `Assets/Core/Perception/BossChaseStateMachine.cs` (신규)
- `Assets/Core/Perception/BossChaseController.cs` (신규)

**수정 파일:**
- `VisionBasedSuspicionManager.cs` - 추격 상태 연동
- `SuspicionMeter.cs` - DETECTED 상태 → BossChaseController에 알림

## 📝 참고

**Boss Enemy vs 일반/정예 구분 방법:**
- Boss: VisionBasedSuspicionManager + SuspicionMeter + BossChaseController 연결
- 일반/정예: NormalEnemyVisionSensor만 연결, 의심도 없음

**의심도 레벨:**
| 레벨 | 범위 | 설명 |
|------|------|------|
| Safe | 0% | 의심 없음 |
| Caution | 30% | 주의 |
| Danger | 60% | 위험 |
| Critical | 80% | 심각 |
| Detected | 100% | 발각 |
